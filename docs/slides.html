Seven Pillars of Autonomy

1. Typed Artifacts

Pydantic models as agent contracts. Schema validation guarantees structure.

2. Externalized Skills

Domain expertise in skills/*.md. QA engineers contribute via markdown.

3. Model Routing

Haiku/Sonnet/Opus per task. Cascade fallback. 30-70% cost savings.

4. Gap Analysis

Detects missing APIs & tools. Auto-generates wrappers. Closes the automation loop.

5. Self-Healing

Repair agent fixes test code bugs. AST validation gates all generated code.

6. Checkpointing

State persists after every stage. Resume from where it stopped.

7. Product Overrides

--product acme overlays product-specific skills without forking.

Skills Architecture

How It Works

  • Domain expertise lives in skills/*.md with YAML frontmatter
  • applies_to: [plan, codegen] controls which agents get the skill
  • Progressive loading: metadata first (~50 tokens), content on demand
  • Token-budgeted: high-priority skills load first, low-priority dropped if tight
  • API skills auto-generated from Python source via AST at each run
  • --product acme overlays product-specific skills

Self-Healing Repair Loop

Classification Heuristics

  • ImportError → test_bug
  • SyntaxError → test_bug
  • NameError → test_bug
  • fixture in trace → test_bug
  • AssertionError (product wrong) → product_bug
  • ConnectionRefused → infra_issue

Only test_bug triggers repair.
Everything else goes straight to triage.

Checkpoint & Resume

How It Works

  • State saved to pipeline_state.json after every stage
  • On --resume, loads state and skips completed stages
  • No wasted LLM calls on crash recovery
  • Budget accounting survives restarts

Getting Started

Setup & Run

# Install
git clone <repo> && cd agent-harness
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

# Configure
export ANTHROPIC_API_KEY=sk-ant-...

# Validate (no LLM calls)
agent-harness run --dry-run

# Place your PRD
cp my-product-spec.md docs/input/

# Run full pipeline
agent-harness run

# View report
open generated/reports/report.html

CLI Commands

run — Full pipeline (ingest → report)

--dry-run | --resume DIR | --docs-dir DIR

plan-only — Stop after test plan

Great for reviewing the plan before executing

execute-only — Run pre-generated tests

--topology NAME to auto-deploy Containerlab

triage-only — Analyze existing results

Feed any pytest JSON report for LLM analysis

token-usage — Cost breakdown by tier & task

Designed for Extensibility

New Domain Skills

Drop a .md file in skills/. No Python needed. Auto-discovered and injected into matching agents at runtime.

skills/domains/sdwan.md
skills/test-patterns/5g-testing.md

Product Overrides

Create skills/products/<name>/ with product-specific priorities and known issues. Run with --product.

agent-harness run \
  --product my-firewall

Skill Packs

Skills are files in git. Share across teams. Import community skill packs. API refs auto-generated from code.

git clone team/5g-skills \
  skills/domains/5g/

New LLM Providers

Implement LLMProvider.call() — one async method. Plug in OpenAI, Ollama, vLLM.

New Topologies

Drop .clab.yaml in config/topologies/. Auto-discovered by plan agent.

Auto-Gen API Skills

API reference skills generated from Python docstrings via AST. Codegen agent always has current API.
